# The Huxley - Soluções em Python

Repositório dedicado ao armazenamento e organização de soluções de problemas da plataforma de ensino de programação **The Huxley**, desenvolvidos em **Python**[cite: 1]. O objetivo deste projeto é servir como material de estudo, consulta e portfólio de lógica de programação e estruturas de dados.

---

## 📂 Estrutura do Repositório

O projeto está organizado em pastas baseadas nos tópicos abordados nas listas de exercícios:

* 📁 **Primeiros_Programas_IDs/**: Introdução à sintaxe, entrada/saída e operações básicas[cite: 1].
* 📁 **Expressões/**: Cálculo matemático e manipulação de expressões[cite: 1].
* 📁 **Condicionais_IDs / Condicionais_2.0_IDs/**: Tomada de decisão e fluxo condicional (`if/else`)[cite: 1].
* 📁 **Laos_IDs / Laço_For_IDs/**: Estruturas de repetição e laços (`for`/`while`)[cite: 1].
* 📁 **Arrays_IDs/**: Manipulação de listas e vetores unidimensionais[cite: 1].
* 📁 **Matrizes_IDs/**: Operações com arrays bidimensionais[cite: 1].
* 📁 **Conjuntos_Dicionários_IDs/**: Uso de `sets` e `dicts` para otimização de buscas e armazenamento[cite: 1].
* 📁 **Ordenação_IDs/**: Algoritmos de ordenação aplicados[cite: 1].
* 📁 **Recursividades_IDs/**: Funções recursivas e resolução de problemas por divisão e conquista[cite: 1].
